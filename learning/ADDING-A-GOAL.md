# Adding a goal

1. Create `<goal-slug>/` and copy the structure from `pullups-20/`.
2. Write `MISSION.md` (why and what success looks like) and `NOTES.md`. Keep them PII-free.
3. Start `progress/log.csv` with the header row (adapt columns if the goal isn't rep-based).
4. Add `<goal-slug>/index.html` (copy and edit `pullups-20/index.html`).
5. Add a row to the table in the root `index.html`.
6. Commit and push to `main`. Pages redeploys automatically.
